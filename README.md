# Chinese Functionalism — Academic Research Workspace

This repository is the collaborative research environment for a book project centered on **Chinese Functionalism**.

## Purpose

The project investigates, conceptualizes, critically examines, and may develop Chinese Functionalism as an analytical framework concerning China's international relations, regional cooperation, strategic interests, and engagement with Southeast Asia.

## Repository Structure

| Directory | Purpose |
|---|---|
| `links/` | Source discovery and bibliographic management |
| `raw-materials/` | Original source documents (PDFs, books, reports) |
| `research/` | Intellectual foundation development |
| `draft/` | Manuscript chapters in Markdown |
| `progress/` | Project status tracking and logs |

## Key Files

- `NORTH_STAR.md` — Central research blueprint. Read before any work.
- `AGENTS.md` — Multi-agent operating rules.
- `draft/CHAPTER_TEMPLATE.md` — Chapter formatting reference.

## Workflow

1. Read `NORTH_STAR.md` first.
2. Read `AGENTS.md` for operating rules.
3. Check `progress/` for current status.
4. Preserve all original materials.
5. Use Markdown for all manuscript work.

## Git

This repository is prepared for GitHub. Run `git remote -v` to check remote configuration.

## Note on Source Materials

PDFs and full-text books are kept in local `raw-materials/` and are not committed to GitHub unless redistribution is permitted. Metadata and links are tracked in `links/`.
