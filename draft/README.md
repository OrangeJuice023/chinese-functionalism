# Draft Directory

Manuscript chapters in Markdown (canonical format).

## Subdirectories

- `chapters/` — One folder per chapter (see `chapters/README.md`).
- `working-notes/` — Drafting notes and outlines.
- `exports/docx/` — Generated DOCX files.
- `exports/pdf/` — Generated PDF files.

## Chapter Workflow

Each chapter folder contains: `chapter-brief.md`, `outline.md`, `research-notes.md`, `draft.md`, `sources-used.md`, `editorial-review.md`, and `figures/`.

`draft.md` is the canonical working manuscript for that chapter. A consolidated manuscript is a compiled output; preserve original chapter files.

Use `CHAPTER_TEMPLATE.md` for chapter formatting. Chapter folders and titles are provisional until book architecture is approved.

Do not mark a chapter finalized without human approval.
