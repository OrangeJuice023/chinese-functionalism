# Chapter Template

Use this template for all manuscript chapters. Based on uploaded chapter samples for formatting reference.

```markdown
# CHAPTER [NUMBER] - [TITLE]

**Argument/Main Idea:** [Central chapter argument]

1. **[Main Section]**
   - **[Supporting Argument]:** [Explanation]
     a. [Supporting details and evidence]
     b. [Additional discussion]

2. **[Main Section]**
   - **[Supporting Argument]:** [Explanation]
     a. [Supporting evidence]
     b. [Counterarguments or limitations]

3. **[Main Section]**
   - [Supporting discussion]
```

## Formatting Rules

- Use numbered main sections.
- Use bullet points for supporting arguments.
- Use alphabetical subpoints for elaboration.
- Use bold subsection labels.
- Ensure every chapter has an explicit argument.
- Maintain academic coherence and logical progression.
- Include source references with consistent Source IDs.
- Distinguish author arguments from empirical evidence and AI inferences.
