# Raw Materials

Original source documents for the Chinese Functionalism project.

## Rules

- Preserve original files. Do not replace source documents with AI summaries.
- Organize by type: academic papers, books/chapters, reports/policy documents.
- `uploaded-references/` — Documents uploaded by the researcher.
- `sample-formats/` — Uploaded chapter samples used as formatting references only (NOT actual chapter assignments).

## Subdirectories

- `academic-papers/`
- `books-and-chapters/`
- `reports-and-policy-documents/`
- `uploaded-references/`
- `sample-formats/`
